# Caderneta Digital

Sistema de Caderneta Digital do Coordenador de Turno.

## 1. Descrição do Projecto

A Caderneta Digital é um sistema desenvolvido para facilitar o registo, a organização e a consulta de informações relacionadas com as actividades do coordenador de turno.

O sistema pretende substituir ou complementar os registos manuais, tornando a gestão das informações mais simples e organizada.

## 2. Objectivo Geral

Desenvolver uma aplicação que permita ao coordenador de turno gerir digitalmente as informações e ocorrências relacionadas com o seu turno.

## 3. Equipa de Desenvolvimento

Projecto desenvolvido no âmbito da disciplina de Engenharia de Software.

## 4. Estado do Projecto

Em fase inicial de desenvolvimento (Sprint 1).
